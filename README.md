# Code Review Navigator
I built Code Review Navigator to simplify the code review process. It creates a persistent map of your codebase, allowing AI coding tools to focus on the most important parts.
## What I Changed
I improved the graph building process and added new features for better code analysis. I also updated the documentation to make it easier to get started.
## Installation
To install Code Review Navigator, run the following command:
pip install code-review-navigator
## Usage
After installation, you can use the following commands to build and update the graph:
code-review-navigator build
code-review-navigator update
## What is Code Review Navigator?
Code Review Navigator is a fork of the code-review-graph project. It builds on top of the original project and adds new features to simplify the code review process.
