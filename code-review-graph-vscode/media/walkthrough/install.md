## Install the Backend

code-review-navigator needs a Python backend to parse your codebase.

**Requirements:** Python 3.10+

**Recommended:** Install via [uv](https://docs.astral.sh/uv/):
```bash
uv pip install code-review-navigator
```

**Alternatives:**
```bash
pipx install code-review-navigator
# or
pip install code-review-navigator
```
